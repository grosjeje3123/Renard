VOIX DU RENARD — mode d'emploi

Ce dossier contient tout pour donner au renard une voix enregistrée, plus naturelle que la voix du système.

  paroles-renard.txt   toutes les phrases, lisibles (identifiant | phrase)
  paroles-renard.csv   la même liste pour le script (id ; origine ; texte ; lecture)
  prompt-voix.txt      la consigne de voix donnée à l'IA (à ajuster à votre goût)
  generer-voix.py      le script qui fabrique les fichiers audio avec l'API OpenAI

COMMENT FAIRE
1. Créez une clé API sur platform.openai.com (la facturation est à l'usage : la liste fait environ 38 000 caractères, soit 1 034 phrases et une quarantaine de minutes d'audio ;
   vérifiez le tarif actuel de la synthèse vocale sur le site d'OpenAI).
2. Dans un terminal, dans ce dossier :
       pip install openai
       export OPENAI_API_KEY="sk-..."          (PowerShell : $env:OPENAI_API_KEY="sk-...")
3. Choisir la voix : python generer-voix.py --essai
   Écoutez les fichiers du dossier essai/ (6 voix x 6 phrases), puis retenez-en une.
4. Générer : python generer-voix.py --voix coral        (remplacez coral par la voix choisie)
   Les fichiers arrivent dans le dossier voix/, nommés <identifiant>.mp3. Si ça s'arrête, relancez : il reprend.
5. Écoutez d'abord les phrases qui parlent de lettres (origine « consigne », « carte ») et celles des majuscules (« Le A majuscule. »…) : si une lettre est mal
   prononcée, corrigez la colonne « lecture » du CSV (ex. « le eu », « un vé ») et relancez avec  --refaire --origine consigne.
6. Remettez le dossier voix/ à la racine du projet (à côté de package.json), sur GitHub : l'APK se recompile tout seul
   avec les voix. (Ou envoyez-moi le dossier.)

Ce qui n'est pas dans la liste (prénom de l'enfant, mot tapé librement dans le Tableau) reste lu par la voix du système.
Si un fichier manque ou ne se lit pas, la phrase est lue par la voix du système : rien ne casse.

À SAVOIR
- OpenAI demande d'indiquer clairement aux utilisateurs que la voix est générée par IA : l'espace parents le dit déjà
  dès que des voix enregistrées sont présentes. Vérifiez aussi leurs conditions pour un usage commercial.
- Les fichiers sont gardés sur la tablette : une fois installée, l'application les joue sans connexion.
